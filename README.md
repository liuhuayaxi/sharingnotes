# Sharing Notes：复习工作台

[打开复习工作台](https://liuhuayaxi.github.io/sharingnotes/)

## 网页使用

1. 在侧栏选择课程和章节，再打开对应课次的笔记。
2. 使用搜索查找知识点；需要时勾选“同时搜索课堂原文”。
3. 使用目录跳转到相关段落，点击正文中的“原文”引用核对课堂文字。
4. 点击配图放大查看，在“课程资料库”或笔记关联资料中打开 PDF。
5. 阅读位置会自动保存在当前浏览器，刷新或重新打开同一篇笔记时继续阅读。
6. 点击右上角“复习热力图”按月查看每日专注时长，可切换月份并点击日期查看记录。页面可见且窗口有焦点时自动计时，切到其他页面或应用时暂停。
7. 使用收藏、个人标注、字号和配色工具辅助复习。所有个人记录保存在当前浏览器。

笔记与课堂原文可以选中，也可使用 Ctrl/⌘ + A 全选；页面拦截复制与剪切，不提供笔记下载或打印。搜索框和个人标注中的文字可正常复制。课程 PDF 可打开或下载。

## AI 读取

让 AI 先阅读 [agents.md](agents.md)，或发送网站上的 [AI 阅读指南](https://liuhuayaxi.github.io/sharingnotes/agents.md)。网站侧栏也有指南入口。

指南说明如何查目录、按需读取笔记、核对配图与资料，以及在回答中引用来源。它只包含使用方法，不收录笔记正文。

## 本地运行

在仓库根目录启动静态服务：

```bash
python3 -m http.server 8000 --directory docs
```

然后打开 <http://localhost:8000/>。

## 验证修改

```bash
npm test
python3 -m unittest discover -s tests -p 'test_*.py'
```

修改 AI 阅读说明时，保持根目录 `agents.md` 和网站目录 `docs/agents.md` 内容一致。网站从 `main` 分支的 `docs/` 发布。
