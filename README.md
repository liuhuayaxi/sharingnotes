# Sharing Notes：课程图文笔记工作台

本地项目文件夹为 `sharingnotes`。GitHub Pages 从 `main` 分支的 `docs/` 发布；远端仓库为 `liuhuayaxi/sharingnotes`，分享地址为 https://liuhuayaxi.github.io/sharingnotes/

当前版本暂停身份认证，不设置校园账号或密码输入框，不向学校登录接口发出请求，也不嵌入校方登录页。早期的直接密码校验已撤下；旧回调入口仅提示认证测试已停用，并清除地址参数。不要绕过浏览器的安全警告；修改页面不等于浏览器的历史风险标记已消失。

发布范围已由资料所有者确认：光电子学、物理光学、微型计算机原理与接口技术、光电子器件（全英文）、通信原理 C。当前是公开可访问的笔记快照，包含笔记正文、公式、正文嵌入的配图及用于引用定位的文字来源；课程资料库另外公开各节课录音和已完成的 AI 友好版 PDF，使用 GitHub Release 附件分发；不含视频、未转换的原始课件、提供商设置、账号配置、学校登录令牌和本机路径。

首页为复习工作台，课堂按具体上课时间从近到远排列。可用功能：课程与课次切换、Markdown 与公式阅读、目录定位、普通全文搜索、课堂原文引用跳转、配图点击放大与原始尺寸查看、当前浏览器收藏与阅读进度、个人标注、字号与配色。笔记与课堂原文（录音转写）只提供在线阅读，不提供打包下载、单篇下载或打印；课程资料库中的录音和 AI 友好版 PDF 仍可下载。没有转写、向量模型检索或笔记生成。外部网页、图片和本机文件链接不会作为可访问资源发布。

## 复制与下载限制

- 已移除笔记 ZIP 打包下载（含可选的课堂文字来源/录音转写）、“下载本篇”和打印按钮；相关的 `package.js`、`zip-worker.js`、`offline-assets.json` 与 fflate 依赖一并删除。
- 保留课程资料下载：资料库与阅读页中的“下载录音 ↗”、PDF 的“打开 / 下载 ↗”。
- `docs/protect.js` 在页面内容上禁止选择、右键菜单、拖拽，以及 Ctrl/⌘ + C / X / A / S / P / U；搜索框、个人标注等输入框保持正常。强制复制（菜单复制、脚本触发的复制等）会被拦截，剪贴板的 `text/plain` 与 `text/html` 都写入等长的随机汉字/符号乱码。
- 样式只改变“能否选择”，不改变屏幕显示；打印媒体下整页隐藏，只显示“不提供打印”的提示。
- 课堂原文（录音转写）在公开的 `docs/data/notes/*.json` 与 `search-index.json` 中不以明文保存：导出时按“笔记 ID + 原文段落 + 分段”生成密钥流，文字先 raw-deflate 压缩，再异或、base64，字段名为 `cipher`（索引中另有 `part`）。浏览器在 `docs/cipher.js` 中解码后显示与搜索，功能不变。`sync_site.py` 发布前会拒绝含明文原文的快照。已发布数据用 `scripts/encode_published_transcripts.py` 一次性迁移（可重复执行，结果与导出脚本一致）。
- 这是浏览器端的威慑措施，不是加密：解码算法就在 `cipher.js` 中，开发者工具或直接读取公开 JSON 后自行解码仍可得到原文；Git 历史中的旧版本也仍含明文。

## 自动更新与课程资料库

`scripts/sync_site.py` 只读本机 QwenASR 回环 API，发现所有已分类课程，分页读取完成的笔记，更新正文、配图、来源和课次目录。现有录音无损重封装为支持拖动定位的 M4A；已有 AI 友好版 PDF 直接分发，不运行 ASR 或 PDF 转换。附件按 SHA-256 命名上传到 `course-media` Release，通过笔记稳定 ID 关联录音，通过笔记保存的 `material_version.course_files` 关联所用 PDF。

使用 `python3 scripts/install_sync_agent.py` 安装当前用户的 launchd 任务，跟随 QwenASR 启停，复用已有资料变更通知；仅在可发布内容变化后执行同步并提交 `docs/data/`，无固定轮询。电脑需开机、联网、QwenASR 正在运行，并保留 `gh` 登录。先发布可用笔记，再同步大附件。首次传输中会显示“正在同步附件”，通过远端完整性校验后才开放播放、下载；正在传输的长批次最多每 10 分钟更新一次可用进度，完成后再发布完整清单。断网、源文件正在变化、版本校验或上传失败时保留线上已有可用资料，下次内容变更或 QwenASR 启动时重试。默认保留已发布而本机暂时不可用的笔记和录音；AI 友好版 PDF 以每次读取到的完整列表为准，本机删除或替换的 PDF 会从资料库撤下。新课程也会自动加入（`未分类` 除外）。

本地事件监听实现与监控页保留在独立的 sharingnotes-monitor 工具中，不合并到此仓库。QwenASR 未运行时无同步监听进程；监控页按需启动，闲置后退出。状态和日志在 `~/.local/state/sharingnotes/`，原录音、课程文件、缓存和密钥不进 Git。手动改动的 `docs/data/` 不会被覆盖，存在其他暂存文件时不会自动提交。同步锁防止重叠执行。停止任务可执行 `launchctl bootout gui/$(id -u)/cn.liuhuayaxi.sharingnotes.sync`，网站上已经发布的快照仍可使用。

课程资料库入口为 `?view=library`，可按课程、标题、日期筛选。阅读页播放器支持倍速，原文旁的“从这里回听”使用同一节录音的实际来源时间，不跳到其他课程。录音和 PDF 在资料库单独下载。

## 手动导出资料

在本机 QwenASR 服务运行时，使用 `scripts/export_courses.py --all-courses --out <待检查的导出目录>`，或者用重复的 `--course` 指定课程。脚本只读本机回环接口，按允许字段重新组成发布 JSON；正文中引用的 PNG 仅从笔记图片接口读取，经 PNG 结构、CRC 和 SHA-256 校验后按内容哈希发布；禁止把完整 API 响应或录音目录复制进仓库。

导出后检查文字、原文映射和 `publish-manifest.json`，再将经确认的快照放入 `docs/data/`。清单包含每篇发布文件及每幅配图的 SHA-256、图片尺寸和字节数。原服务、源笔记及正在进行的任务不被修改。

## 本地验证

- `npm test`
- `python -m unittest discover -s tests -p 'test_*.py'`
- 用静态 HTTP 服务打开 `docs/`，检查真实笔记、公式、搜索和原文定位。

Marked、DOMPurify 和 KaTeX 均为本地依赖，来源版本和许可证位于 `docs/vendor/`。运行时没有第三方脚本、远程字体、统计或模型调用。

## 认证实验结论

学校官方回跳曾显示“找不到应用”。后续在本地验证：官方登录页可被显示在框架中，但父网页读取其内容会被浏览器以 `SecurityError` 阻止。显示校方页面不等于取得其身份授权。`postMessage` 也需要校方页面主动配合。正式的官方登录接入仍需要学校认可本站的回调和身份返回方式；目前未启用。

## 浏览器安全复核

2026-10-17，Google 公开安全报告仍显示该地址存在风险标记。已撤下旧校园密码校验代码，并在站点所有者明确授权后提交一次整改复核，官方表单显示“提交成功”。这不代表风险标记已经清除；不要绕过浏览器警告。当前部署的阅读页没有校园账号密码表单，也没有向学校认证接口发出请求。

## 配图与阅读配色

当前快照包含 33 篇笔记和 80 幅内嵌 PNG。图片逐幅保留原始字节，不上传整份课件 PDF。只有清单中明确登记的同源图片路径可以渲染，外部地址、数据 URI 与本机路径均不作为笔记配图加载。图片有宽高占位和按需加载，并可点击放大、查看原始尺寸。

纯黑配色在屏幕上将页面、阅读区、侧栏、表格、原文面板和弹窗设为黑底白字。图片保留原始颜色，不反转图中曲线或标注。打印已停用。
