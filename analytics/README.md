# Sharing Notes 使用统计

管理看板：https://sharingnotes-analytics.sharingnotes-service.workers.dev/

首次使用管理员口令登录，在“账号与安全”中创建通行密钥，按浏览器提示用 Touch ID / Face ID 或密码管理器保存。面板支持最近 7／14／30 天及自定义日期，统一按 UTC+8 自然日汇总，并与上一等长周期对比（上一周期超出约 30 天保留范围时不对比）。汇总包含访问、去重访客、笔记打开、专注时长、会话、复制与课堂原文。趋势可按日或按周切换，访问次数图同时画出去重访客。另有星期分布、星期×小时热力、新访客/回访、会话跨度、页面分布、来源域名和国家。点击趋势图、日期卡片或每日明细中的日期，可查看当天总结、24 小时专注分布、热门笔记、阅读节点、课程投入占比与分页访问足迹。笔记表现支持搜索和排序，并显示复制与原文次数。访客可展开分页明细。浏览器、系统、设备和语言按所选范围的全部环境上报批次计算，诊断表显示最近 100 条。导出按钮下载近 30 天 JSON，包含来源与国家汇总。

访问来源只保存域名或“直接访问”，不保存路径、查询参数或复制的文字。国家代码只在访客开启环境分享时，从 Cloudflare 的国家头写入。搜索只计次数，不保存搜索词。

访问、笔记打开、专注时长和阅读节点来自全部汇总记录。访客、会话、时段和访问足迹来自开启访问关联的记录，按事件发生时间筛选。环境诊断按接收时间筛选。汇总卡片的访客与会话在整个日期范围内去重，访客列表最多显示最近活跃的 200 个。最早保留记录之前的日期显示“未记录”。

使用数据按天汇总。访问关联默认开启：本地随机访客 ID 长期保存，换 IP 后仍能关联同一浏览器。关闭后停止上传并删除本地 ID；再次开启会生成新 ID。看板可点击访客查看会话、笔记与专注时长。环境诊断独立保存 IP、User-Agent、平台、语言和视口，不保存 Canvas、音频、字体枚举，开启访问关联后，环境信息也可随关联事件保存。设置关闭后，后续请求不保存环境诊断，但基础统计继续。随机事件 ID 仅用于重试去重。

诊断和去重记录按接收时间保留 30 天，使用汇总按自然日保留约 30 天。每小时及收到收集请求时清理过期数据。Cloudflare 数据库恢复快照和平台网络处理受其自身保留规则约束，应用清理不等同于平台备份擦除。

## 部署与维护

在仓库根目录先迁移数据库，再部署 Worker，最后发布阅读站。Worker 先上线后，阅读站里的复制、课堂原文、搜索和页面事件才会被接受；若顺序相反，含这些新事件的上报批次会被旧 Worker 拒绝。

```bash
npx wrangler login
npx wrangler d1 migrations apply sharingnotes-analytics --remote --config analytics/wrangler.jsonc
npm run deploy --prefix analytics
```

`migrations/0004_context.sql` 增加来源、国家字段和 `traffic` 表。上面的迁移命令会应用到远程库。阅读站随仓库的 GitHub Pages 发布；`docs/app.js` 与 `docs/analytics.js` 使用 `?v=insights1` 避免旧脚本缓存。

管理员口令通过 `wrangler secret put ADMIN_SECRET --config analytics/wrangler.jsonc` 配置，不能写入仓库。更换口令会使旧登录会话失效。

```bash
npm test --prefix analytics
npm test
```

免费版达到额度后日志接收可能失败，网页阅读继续，待发送队列最多 200 条、保存 5 天。公开上报接口不能证明事件来自真实用户；Origin 校验和实例频率限制只减少误用，统计用于趋势分析。

管理员通行密钥属于授权配置，不按 30 天清理；只有统计日志按期限清理。私钥由设备或密码管理器保管，服务端只保存公钥。
